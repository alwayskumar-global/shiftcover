Theming the Scheduler with our tokens

The roster stays a real Bryntum Scheduler. We change how it looks with CSS only: one paste-in stylesheet, status classes attached through eventRenderer, and a handful of config values. Nothing renders inside a block except an icon, a title and a subtitle.

Recommended base theme: Svalbard

Why Svalbard.

  • Flat and modern with few borders. Our meaning lives in fills, hatching, dashed outlines and icons; a border-heavy base (Visby) would compete with those.
  • It is the default theme in Bryntum 7, where all products moved to CSS-variable theming, so our overrides are plain CSS with no SASS build step.
  • Neutral surfaces let our warm paper tokens show through instead of fighting a tinted base.

Alternatives.

  • Visby: second choice if you want hairline structure around every cell. Expect to remove borders in Part 3.
  • High contrast: keep in mind as a future accessibility mode; our status tokens would need a re-map.
  • Stockholm / Material3: not recommended. Stockholm is a refreshed classic look and Material3 adds tonal elevation, both further from the kitchen-pass feel.
  • If the project is on Bryntum 6 or earlier (SASS themes), use Stockholm and skip Part 2; Parts 3 to 5 still apply.

Deliberately not used

  • No charts, progress bars or avatars inside event blocks. Only icon, title, subtitle, fill.
  • No Bryntum color palette (eventColor) or built-in event styles for status. They cannot express hatch or dashed outlines the way our classes do.
  • No custom drawing for the gap highlight: it is a row class plus a CSS bar.
  • No dark theme yet. Our scheduler tokens all point at semantic tokens, so dark is a re-map later.
