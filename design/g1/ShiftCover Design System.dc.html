01 · Signature idea

The Pass

A kitchen pass is where a plate is handed from one person to the next and nobody has to ask where it is. The Money Timeline is the product's one recurring visual: three stations on a rail, Authorized, Captured, Paid, each with an amount, a plain-English sentence, and a copyable reference. The Wave Timeline reuses the exact same rail so the manager learns one pattern. Done = solid node, Now = ringed node, Next = dashed node, always with a text label. Static fallback with reduced motion: the ring stops pulsing and stays drawn.
